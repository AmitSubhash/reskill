Claude Code ships hooks for every prompt, tool call, and stop event. reSkill wires into those hooks, watches your live transcript, and renders a single question whenever Claude is mid-thought. You answer, Claude finishes, you’ve both shipped something.

How it works

  1. Install the hooks. reskill install writes entries to ~/.claude/settings.json for UserPromptSubmit, PreToolUse, PostToolUse, and Stop. Reversible; backs up your existing file.
  2. Claude thinks. You see a question. The question is grounded in your live transcript — your actual code, not Leetcode trivia. Answer with 1–4.
  3. The wrong answers stick harder. Fast-wrong answers are flagged as high-confidence misses — re-surfaced later via reskill review. Hypercorrection effect (Butterfield & Metcalfe 2001).

Scheduler

Questions are picked by a small scheduler: overdue items from spaced-repetition first, then new concepts, interleaved only across confusable clusters so you don’t drill one topic in a row. Difficulty targets the 85% rule from Wilson et al. 2019. Format rotates so you’re not always answering multiple-choice. Source of every decision: reskill/scheduler.py, with citations in the docstrings.

FAQ

Do I need an API key?

No. Quiz generation reuses the claude CLI you already have installed. The built-in question bank covers 50 concepts with zero network calls.

Does it send my code anywhere?

Only to whatever claude already sends when you use Claude Code. reSkill doesn’t make independent network calls.

What if I don’t use tmux?

Skip reskill claude. Use reskill session after each coding session, or wire reskill next to a Stop-hook for inline prompts.

Can I disable it temporarily?

reskill uninstall removes only reSkill’s entries from your Claude settings. Everything else stays intact.

Who is this for?

Developers who use Claude Code heavily and have noticed their focus drifting during the 10–30 second tool-call pauses. If you don’t reach for your phone during those pauses, you don’t need reSkill.
