how it works

Three seconds between your prompt and the quiz.

01

Install the hooks.

reskill install wires into Claude Code’s UserPromptSubmit, PreToolUse, PostToolUse and Stop. Reversible. Preserves your existing statusline.

02

Claude thinks. You see a question.

The question is grounded in your live transcript — your actual code, not Leetcode trivia. Answered in 20–45 seconds with keyboard 1–4.

03

The wrong answers stick harder.

Fast-wrong answers get flagged “sticky” — the hypercorrection effect means these are where learning bites deepest. Reviewed later with reskill review.

Replace the scroll. Literally.

what’s inside

Research-grounded. Terminal-native. Yours.

SM-2 + 85% rule

Questions sorted by spaced-repetition urgency, then by Wilson et al. 2019 error-rate sweet spot. Interleaved across confusable concept clusters.

Questions from your diffs

reskill gen --live feeds your actual Claude transcript to the LLM and returns a question about what you just built. Validated against the NBME item-writing rubric.

tmux or two windows

reskill claude splits tmux with the quiz on the side. On macOS without tmux, it opens a second Terminal window. No overlay hackery.

Learning map

reskill topics shows 50 concepts grouped by cluster with your per-concept mastery. See the gaps before they bite.
